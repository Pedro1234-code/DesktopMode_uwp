## Work applied after examining this run

The readback compositor previously forced a full redraw on every frame. It now retains the FBO, reports buffer age 1, requests complete redraw only on initial allocation/resize or a failed readback, and skips CPU readback/publication when there is no damage. It does not submit EGL damage for the dummy pbuffer. Animated frames still incur full-image readback and bitmap upload; this change does not eliminate that cost.
